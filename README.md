# Personal Website
Personal Website using React, HTML, and CSS to show Github, LinkedIn, and a short introduction about me. Currently a work in progress.

## How to Run the website
It is recommended to put the public and src files under a single root directory (in my case it is called my-app since I used the command npx create-react-app my-app to make a template app), and then after navigating into the root directory to type in "npm start" to then generate the localhost link to then render the app in your chosen browser. As a tip, you can run the command "npm run" to show the available commands that can be used in the app.
